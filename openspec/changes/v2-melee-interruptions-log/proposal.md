## Why

После PR #60/#61 укус v2 с подготовкой 1q безусловно отменяет обычный удар длительностью 4q. В ближнем бою последовательность нелетальных укусов лишает живого охотника возможности ударить. Для ручного playtest также отсутствует полный причинный console log.

## What Changes

- В v2 нелетальный обычный укус сохраняет обычный ближний удар охотника; смерть до дедлайна отменяет удар. Постановка рогатины и прорыв сохраняют прерывание.
- Управление возвращается после завершения продолжающейся команды и recovery, с полным пакетом совпавших событий.
- Ручной режим получает console log опубликованных результатов, без preview/render и без вывода из domain.
- Веса, урон, HP и длительности сохраняются; ordinary и regression профили не меняются.
- Приёмка: детерминированные тесты цепочки, повторных укусов, общих дедлайнов, смерти и input gate; JUnit, Desktop smoke и строгая OpenSpec validation; полный пример журнала.

## Capabilities

### New Capabilities
- `combat-debug-log`: журнал принятых команд ручного боя на основе TacticalAttackResult.

### Modified Capabilities
- `tactical-attack`: завершение обычного удара v2 после нелетального укуса.

## Impact

WorldSceneState и доменные тесты; внешний formatter и точка публикации FirstScreen; Desktop playtest/smoke. Новые зависимости и второй источник боевого состояния не нужны. Отдельный PR; change остаётся активным, без sync и archive до приёмки.
