## Context

FirstScreen использует ShapeRenderer, OrthographicCamera и FitViewport(20,15); клетка TacticalGrid равна 1, origin=(0,0), ось Y направлена вверх. Камера следует за охотником, zoom=1 в обоих режимах. Фигуры — круги радиусов 0.4 и 0.3; вход в тактику перемещает их к центрам клеток с визуальной интерполяцией 0.22 s, масштаб камеры не меняется. В assets есть только шрифт, компактного волка нет.

## Goals / Non-Goals

**Goals:** измерять реальные габариты с общей конфигурацией камеры и клетки; отделить visual container от footprint; обеспечить повторяемые screenshots.

**Non-Goals:** новые правила, боевой режим внутри Lab, импорт SVG, rig, финальный арт-стандарт.

## Decisions

- Извлечь только константы в PrototypeViewConfig, используемый FirstScreen и Lab. Не наследовать FirstScreen: он объединяет renderer и боевую симуляцию. Lab использует те же libGDX ShapeRenderer/камера/viewport без рефакторинга боя.
- Lab находится в core/graphicslab; domain не меняется. TacticalGrid используется для координат, но не WorldSceneState. Переключение режима — только сравнение свободного и клеточного позиционирования.
- Вместо SVG использовать геометрические формы существующего ShapeRenderer: это разрешённая заглушка без новых библиотек. Локальные координаты art задаются сверху вниз, преобразование в world: x=anchorX+(u-pivotX)*scale/64; y=anchorY+(pivotY-v)*scale/64. Ground line проходит через pivot.
- Small/Large наследуют относительное положение pivot от Medium (50% ширины, 108/128 высоты); это явная начальная гипотеза. Сохранять прозрачный запас ниже ground line, не выравнивать нижний край с клеткой.
- Отдельный desktop launcher и Gradle task не затрагивают Main/Android navigation. Автоматический smoke launcher получает отдельный task, screenshots сохраняет в build.

## Risks / Trade-offs

- Геометрическая заглушка не проверяет фильтрацию PNG → документация ограничивает выводы геометрией и читаемостью форм.
- Мелкие детали при 640×480 → показать реальные экранные размеры; рекомендация по деталям предварительная.
- Lab не запускает бой → существующие тесты и desktop smoke проверяют сохранность основного режима отдельно.
