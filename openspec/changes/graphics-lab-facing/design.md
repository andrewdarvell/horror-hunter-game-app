## Context

GraphicsLabScreen использует ShapeRenderer, OrthographicCamera, FitViewport(20,15), клетку 1 world unit. LabFigure хранит размер, scale и anchor. Фигуры сортируются по Y убыванию; ground anchor совпадает с root pivot. Свободны Q/E, V, H, J, K, U/I, O/L, Backspace.

## Goals / Non-Goals

**Goals:** фиксированная относительно клетки геометрия направления, управляемое сравнение на существующей камере, повторяемая визуальная проверка.

**Non-Goals:** восемь изображений, поворот тела, domain facing, боевые/AI правила, выбор окончательного стандарта.

## Decisions

- Facing — enum внутри graphicslab с clockwiseDegrees и углом libGDX (90 - clockwiseDegrees). Состояние хранится в LabFigure. Никакие методы движения его не меняют.
- FacingIndicator — небольшой renderer в graphicslab, геометрия задаётся в долях клетки. Arrow с тёмной окантовкой, Notch с круглой деревянной подставкой, Sector через alpha blending с восстановлением GL состояния.
- Сектор — отдельный общий ground pass до фигур. Подставка/Arrow — до соответствующей фигуры в Y-порядке; контрастный выступ Notch — после её тела, как кромка подставки. Это помогает удержать notch видимым; ограничение наложения на низ фигуры оценивается визуально.
- Q/E поворот, V вариант, H selected/all, Backspace сброс выбранного facing; J solo selected, K диагностический HUD для screenshot; U/I угол сектора, O/L радиус. Space дополнительно сбрасывает facing всех в N.
- Без копирования игровой симуляции: все компоненты в Lab. Screenshot smoke проверяет три режима × восемь направлений, соседей и разный масштаб/окна.

## Risks / Trade-offs

- Анфас перекрывает северную часть ground plane → показывать реальные перекрытия на screenshots и описать для каждого варианта.
- Маленький notch может теряться в сетке → тёмная кромка и светлый выступ, чистый режим без диагностических guides.
- Сектор напоминает зону атаки → явно обозначить только графический эксперимент; не интегрировать в combat.
