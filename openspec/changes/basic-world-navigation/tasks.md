## 3. Проверки и отчёт

- [ ] 3.1 Выполнить `./gradlew :domain:test` и зафиксировать результат доменных тестов.
- [ ] 3.2 Выполнить `./gradlew :core:classes :lwjgl3:classes` и зафиксировать результат компиляции интеграционных модулей.
- [ ] 3.3 Запустить `./gradlew lwjgl3:run` и вручную проверить движение по четырём направлениям, диагональ без ускорения, следование камеры и переключение debug-сетки.
- [ ] 3.4 Во время desktop-запуска изменить размеры и свернуть/восстановить окно, проверив отсутствие исключений, изменения скорости и смещения сетки относительно мира.
- [ ] 3.5 При доступном Android SDK выполнить `./gradlew :android:assembleDebug`; при недоступности явно указать ограничение вместо утверждения об успешной проверке Android.
- [ ] 3.6 В отчёте PR перечислить автоматические и ручные проверки, параметры прототипа, известные ограничения и приложить снимок или запись минимальной сцены по возможности.
