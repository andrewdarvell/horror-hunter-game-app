# Проверка v2: доменный этап

Задачи 6.1–6.7 реализованы в отдельной implementation-ветке `feat/spear-wolf-v2-domain`. Ручной launcher в этом этапе сохраняет regression profile; интерфейс и игровая приёмка v2 относятся к задачам 7.1–7.5. Этот отчёт не заменяет исторические проверки S/R и не подтверждает ручную приёмку v2.

## Выполненные проверки

- `./gradlew :domain:test :core:test :core:classes :lwjgl3:classes --console=plain` — exit code 0; 240 domain и 63 core теста, без failures, errors или skipped.
- `openspec validate boar-spear-wolf-clash --strict --no-interactive` — успешно.
- `git diff --check` — успешно.
- `TacticalTimelineTraceTest` прошёл с прежним эталоном; файл baseline не изменён. Прежние сценарии рогатины выполняются в regression profile.

Gradle проверялся с доступом к пользовательскому cache вне sandbox: sandbox запрещает запись lock-файла Gradle Wrapper. Предупреждения компилятора о source/target Java 8 не являются ошибками сборки.
