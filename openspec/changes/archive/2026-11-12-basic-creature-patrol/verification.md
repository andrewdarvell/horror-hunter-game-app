# Проверки basic-creature-patrol

Дата: 2026-11-12. Реализация выполнена по `specs/creature-patrol/spec.md` и `design.md`; приёмка и архивирование ещё не выполнены.

## Автоматические проверки

- `./gradlew :domain:test :core:classes :lwjgl3:classes` — успешно после последнего изменения кода: 53 теста, 0 failures, 0 errors, 0 skipped. Включены прежние тесты охотника, препятствий и сетки.
- Новые тесты проверяют полный путь круга относительно AABB, пересечение между безопасными endpoints, радиус, касание сторон и угла, безопасную область около угла, обратное направление и некорректные аргументы.
- Тесты патруля проверяют начальную паузу, маршруты из двух и трёх точек, развороты и повторение, скорость по оси и диагонали, точное прибытие, расход остатка времени, разные разбиения интервала, валидацию и защитную копию маршрута. Отдельный тест проверяет конкретный маршрут на трёх препятствиях прототипа.
- Дополнительный эксперимент с шагом `0.1 s` обнаружил задержку переключения фазы на кадр из-за остатков порядка `1e-16 s`. Расчёт уточнён допуском округления времени в восемь ULP полной фазы; регрессионный тест проверяет позицию, цель, направление и таймер. Пространственный epsilon не используется. Уточнение записано в design.
- `javap -verbose` для `CreaturePatrolState.class` — major version 52 (Java 8). Новые production-классы используют только собственные доменные типы и стандартную Java; build-конфигурация и зависимости не менялись.
- `./gradlew android:assembleDebug` — успешно, в том числе после исправления временных границ. APK: `android/build/outputs/apk/debug/android-debug.apk` (результат сборки, не включается в Git).
- `openspec validate basic-creature-patrol --strict` — успешно.
- `git diff --check` — без замечаний.

Gradle запускался с доступом к пользовательскому cache вне sandbox. Компилятор предупреждает об устаревших `source/target 8`; ошибок компиляции нет.

## Desktop: остаётся ручная проверка

`./gradlew lwjgl3:run` запущен; наличие процесса `ru.darvell.game.hhg.lwjgl3.Lwjgl3Launcher` подтверждено через `jps`. В доступном инструментарии нет native UI для осмотра окна и управления игрой. Это подтверждение запуска процесса, а не визуальной корректности. Тестовый процесс завершён мной через SIGTERM после проверки; поэтому `lwjgl3:run` завершился с exit 143. Успешный выход GUI-приложения не подтверждён.

Задача 4.3 закрыта по указанию владельца проекта без завершённой ручной проверки. При ручном запуске нужно проверить несколько циклов патруля и паузы без ввода, WASD и коллизии охотника, отсутствие реакции существа на охотника, переключение G, уход существа за viewport и продолжение симуляции, resize и сворачивание. Скриншоты и записи не получены.

## Android: сборка выполнена, runtime остаётся непроверенным

Android SDK и платформа 36 установлены. Подключённых устройств в `adb devices` нет. Предпринят запуск существующего AVD `Medium_Phone` без окна с software GPU. Эмулятор сообщил о зависших QEMU CPU threads и не появился в ADB; эмулятор затем самостоятельно завершился с exit 139 (SIGSEGV). APK не устанавливался, рендер и lifecycle на устройстве не проверены.

Задача 4.4 закрыта по указанию владельца проекта без runtime-проверки; для её проведения нужен работающий эмулятор или устройство. Сборка APK не считается подтверждением runtime-проверок.

Реализация и автоматические проверки выполнены. Все 16 задач отмечены завершёнными. Задачи 4.3 и 4.4 закрыты по прямому указанию владельца проекта; это не подтверждение успешных ручных проверок.
